安装与使用指南

本指南帮助您快速上手《澄页》ClearTab 的核心布局、搜索、浮动书签栏与配置迁移。

1. 安装扩展

  • Chrome 网上应用店：即将发布，正式上架后可直接一键安装并自动接收更新。
  • 零额外书签导入：首次打开新标签页即可直接展示您的 Chrome 原生书签栏内容，无需导入或注册账号。

2. 四种主页布局模式

  • 桌面文件夹模式：以 2×2 缩略图展示文件夹，点击在轻量浮层中展开多级目录。
  • 文件夹展开模式：在主页直接按纵向或平铺多列分组展开展示各目录书签。
  • 瀑布流模式：一文件夹一列自动排列，适合高频书签多列同屏浏览。
  • 自由布局模式：可通过右上角「编辑布局」或空白处右键菜单进入主页直接拖拽文件夹位置与调节宽高，支持网格吸附、磁吸对齐辅助线与撤销/重做。

3. 网页搜索与书签检索

  • 在搜索框输入关键词可实时检索全部 Chrome 书签；输入网址（如 github.com）可直接回车访问。
  • 默认使用「Chrome 默认搜索引擎」（通过 chrome.search.query() 遵循您的 Chrome 浏览器设置），也可点击搜索框左侧图标临时切换其他内置或自定义搜索引擎。

4. 可选浮动书签栏

  • 默认处于关闭状态，安装时不申请网页访问权限。
  • 在「设置 → 浮动书签栏」中开启并同意浏览器网页权限提示后，在普通网页顶部悬停即可呼出，移开自动隐藏；支持随时一键撤销权限或关闭。

5. 本地版向商店版配置迁移

如果您此前曾使用过本地测试版，需要迁移主题、自定义图标或自由布局坐标：

  1. 在旧版扩展中打开「澄页设置 → 数据与备份」，点击「导出 JSON 备份」保存配置文件。
  2. 安装商店正式版后，在「设置 → 数据与备份」中点击「导入 JSON 备份」选择刚才保存的文件即可完成迁移。
  3. 您的 Chrome 原生书签由浏览器直接维护，无需任何迁移操作。
