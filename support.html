常见问题 (FAQ)

1. 《澄页》会修改或删除我的 Chrome 原生书签吗？

不会擅自修改。所有新增、重命名、移动或删除操作仅在您主动触发时执行；恢复扩展默认设置或清除自定义图标数据时，均不会影响 Chrome 原生书签。

2. 我很喜欢原来的「深潮青·澄序」配色，如何切换回来？

打开右上角「设置 → 主题与外观」，点击「深潮青·澄序 (Deep Tide Teal)」内置主题卡片即可一键切换；若您是从旧版本升级而来，系统已自动为您保留原有深潮青配置。

3. 为什么浮动书签栏在 chrome:// 或 Chrome 商店页面不显示？

出于浏览器安全策略限制，Chrome 不允许任何扩展向 chrome://、chrome-extension:// 或 Chrome 网上应用店页面注入内容脚本。在普通 http:// 与 https:// 网页中可正常使用。

4. 如何彻底关闭或撤销浮动书签栏权限？

在「设置 → 浮动书签栏」中关闭开关，或点击「撤销网站访问权限」即可立即移除动态注册的脚本与授权。
