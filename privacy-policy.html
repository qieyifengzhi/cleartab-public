《澄页》ClearTab 隐私政策

生效日期：2026-11-26 适用版本：v1.5.7 及以上 开发者：Sylvan 公开反馈邮箱：qieyifengzhi@gmail.com

《澄页》（ClearTab）是一款免费、无广告、无内置打赏的 Chrome 新标签页与书签管理工具。本隐私政策基于《澄页》实际源码与运行机制编写，如实说明本扩展对数据的访问、存储、传输及删除方式。

1. 数据访问与本地存储范围

  • Chrome 原生书签数据访问与管理（bookmarks 权限）：仅用于在本地读取、展示、搜索及按您的明确操作新建、重命名、移动、重排或删除 Chrome 原生书签与文件夹。本扩展不建立独立云端书签库，也不篡改原生书签标题或网址来夹带额外数据。
  • Chrome Storage 本地配置存储（storage 权限）：主题配色（含默认「简约中性」、内置「深潮青·澄序」及自定义主题）、深浅色模式、主页布局模式、自由布局坐标、搜索引擎列表、自定义图标及本地壁纸仅保存在您当前浏览器的 chrome.storage.local 中。
  • 网站 Favicon 获取方式（favicon 权限）：通过 Chrome 原生 Manifest V3 /_favicon/ 接口从浏览器本地缓存读取书签网站图标；未命中缓存时在本地生成首字缩写图标。绝不会将您的书签网址发送至任何第三方 Favicon 服务器。
  • 网页搜索与搜索服务（search 权限）：新标签页搜索框默认选用「Chrome 默认搜索引擎」，提交网页搜索时通过 Chrome 原生 chrome.search.query() 接口交由您在 Chrome 中设置的默认搜索引擎执行。若您在搜索框下拉菜单中主动切换至其他内置或自定义搜索引擎，搜索关键词将直接跳转至您所选择的对应搜索服务商（如 Google、Bing、百度、DuckDuckGo 或您自行添加的搜索模板）。本扩展不截获、不中转、不修改浏览器默认搜索引擎，也不记录搜索历史。
  • 浮动书签栏可选网站访问权限（optional_host_permissions：http://*/*、https://*/*）：扩展安装时默认不申请任何网页访问权限。仅当您在设置中主动开启「浮动书签栏」时，浏览器才会弹窗请求该权限，用于在普通网页顶部通过 Shadow DOM 覆盖显示书签栏。本扩展不读取网页表单、密码、网页正文或浏览历史，且您可随时在设置或 Chrome 扩展管理页撤销该权限。

2. 实际外部网络请求

  • 《澄页》不包含任何统计分析、广告归因、崩溃上报或用户行为追踪脚本，不向开发者或第三方服务器上传任何数据。
  • 扩展所需的全部脚本、样式与内置图标均随安装包本地加载。
  • 仅当您主动点击书签、在搜索框输入网址直达或提交搜索关键词时，浏览器才会按您的指令向目标站点或您所选择的搜索引擎发起常规网页导航请求。

3. 数据处理、传输、共享与删除机制

  • 不收集、不传输、不出售、不共享：我们不收集、不向外部传输、不出售也不与任何第三方共享您的书签数据、配置或个人信息。
  • 本地数据删除方式：您可随时在「澄页设置 → 数据与备份」中点击「清除自定义图标数据」或「恢复默认设置」（该操作不会删除您的 Chrome 原生书签）；卸载《澄页》扩展后，Chrome 将自动清除该扩展关联的全部 chrome.storage.local 数据。

4. Chrome Web Store Limited Use 声明

《澄页》对通过 Chrome 扩展 API 获取的数据的使用严格遵守 Google《Chrome Web Store User Data Policy》（包括 Limited Use 限制使用要求）：

  • 数据仅用于在本地向用户提供界面中明确可见的书签管理与新标签页功能；
  • 绝不将数据用于广告投放、用户画像、信用评估或转让给任何第三方。

5. 联系方式

如您对本隐私政策或数据处理方式有任何疑问，请联系开发者 Sylvan：qieyifengzhi@gmail.com。

ClearTab Privacy Policy (English)

Effective Date: 2026-11-26 Applies To: ClearTab v1.5.7 and later Developer: Sylvan Support Email: qieyifengzhi@gmail.com

ClearTab is a free, ad-free Chrome New Tab and bookmark organization extension. This Privacy Policy accurately describes how ClearTab accesses, stores, and handles data based on its actual source code and runtime behavior.

1. Data Access & Local Storage

  • Native Chrome Bookmarks (bookmarks permission): Accessed locally solely to display, search, and—when explicitly initiated by you—create, rename, move, reorder, or delete native Chrome bookmarks and folders.
  • Local Preferences (storage permission): Theme presets ("Neutral" default, "Deep Tide Teal", and custom themes), light/dark mode, layout modes, free-layout coordinates, search engine preferences, custom icons, and local wallpapers are stored exclusively in your browser's chrome.storage.local.
  • Website Favicons (favicon permission): Resolved locally via Chrome's Manifest V3 /_favicon/ API from browser cache, falling back to locally generated monogram badges. ClearTab never sends your bookmark URLs to third-party favicon services.
  • Web Search & Search Providers (search permission): Every New Tab defaults to your browser's default search engine via Chrome's native chrome.search.query() API. Only if you explicitly switch to another built-in or custom search engine in the dropdown will your query be sent directly to that chosen search provider. ClearTab never intercepts, proxies, logs, or alters your Chrome default search engine setting.
  • Optional Website Access (optional_host_permissions: http://*/*, https://*/*): Not requested upon installation. Requested only when you explicitly enable the optional Floating Bookmark Bar in Settings, solely to render a Shadow DOM bookmark overlay at the top of web pages. ClearTab never reads form inputs, passwords, page contents, or browsing history, and you can revoke this permission at any time.

2. External Network Requests

  • ClearTab contains no analytics, telemetry, ads, or remote code execution, and never transmits user data to any developer-controlled or third-party server.
  • All extension scripts, styles, and built-in icons are bundled locally inside the extension package.
  • External network requests occur only when you explicitly click a bookmark, navigate to a typed URL, or submit a query to your chosen search engine.

3. Data Processing, Sharing & Deletion

  • ClearTab does not collect, transmit, sell, rent, or share user data with any third parties.
  • You may delete locally stored extension data at any time via Settings → Data & Backup ("Clear Custom Icon Data" or "Reset to Defaults", which never deletes native Chrome bookmarks), or by uninstalling the extension, which removes all chrome.storage.local data.

4. Chrome Web Store User Data Policy & Limited Use

ClearTab's use of information received from Chrome APIs strictly adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements: data is used solely to provide user-facing bookmark and New Tab features prominent in the UI and is never transferred, sold, or used for advertising or profiling.

For privacy inquiries or support, contact developer Sylvan at qieyifengzhi@gmail.com.
