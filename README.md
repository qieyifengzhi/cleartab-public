# 澄页 ClearTab 公开支持网站 (`cleartab-public`)

本仓库仅用于托管 Chrome 扩展 **《澄页》ClearTab** 的公开产品支持页面与隐私政策（GitHub Pages），**不包含**扩展源码、开发日志、私人配置或任何用户数据。

## 页面结构

- `index.html`：产品主页（简介、核心特性、实机截图与支持入口）
- `privacy-policy.html`：完整中英文隐私政策
- `guide.html`：安装与使用指南（含本地版向商店版配置迁移）
- `changelog.html`：面向用户的版本更新记录
- `support.html`：常见问题解答与支持联系渠道
- `styles.css`：简约中性（Neutral）响应式样式表（自动跟随系统浅色/深色模式）
- `assets/`：品牌图标与脱敏产品演示截图
